# RT-DETR provenance notice

Parts of the model, geometry, query-selection, postprocessing, and checkpoint
compatibility behavior are adapted from
[lyuwenyu/RT-DETR](https://github.com/lyuwenyu/RT-DETR) at commit
`068dfde65f2667ad6555883c69d73de886518cad`. The named model presets and
RT-DETRv2 state-dictionary behavior are adapted from the same repository at
commit `29320b6fd828f8e0987a71426cf2d961b09dfed7`. Both revisions are licensed
under Apache-2.0.

The repository retains pinned source files, exact hashes, and detailed change
provenance under `third_party/RT-DETR`. Those test-only sources are not included
in this distribution.
