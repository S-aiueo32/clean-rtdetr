# NVIDIA L4 native bf16 validation

The supplied GPU result bundle reports **`passed_native_bf16`** on one
**NVIDIA L4**, with no failed probe checks. The result was reviewed and recorded
on 2026-09-11. The [machine-readable report](bf16-l4.json) preserves the measured
results, source manifest, artifact hashes, and validation scope.

## Limits

This establishes native bf16 execution for the bounded synthetic probe on L4.
It does not validate the complete R50vd preset at 640x640, pretrained COCO AP,
full training or convergence, latency/throughput, DDP, GPU checkpoint resume,
bf16 ONNX export, or all-bf16 parameters.

The tested snapshot had a CPU-only Lightning execution guard. The probe recorded
that restriction without bypassing it; its successful training checks used the
raw `DenoisingTrainingModel` and `SetCriterion`. Later CUDA Lightning support is
documented separately in [GPU execution](../docs/gpu-validation.md); this report
does not validate that later implementation.

The earlier Kaggle T4 run established emulated bf16 execution only. This L4
result additionally verifies that the tested GPU supports native bf16.
